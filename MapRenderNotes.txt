# 🧭 Phase 1 — Semantic Filtering (Fix the “wrong windows” problem)

### Goal

Ensure only valid building surfaces receive façade treatment.

### Prompt

> I have OSM-derived geometry in Three.js. Each object includes OSM tags (e.g. `building=*`, `man_made=*`, etc.).
>
> Help me design a filtering system that classifies geometry into:
>
> * valid building walls
> * roofs
> * non-building structures (towers, statues, monuments)
>
> Include:
>
> * specific OSM tags to include/exclude
> * geometry heuristics (normals, footprint size, height)
> * example pseudo-code for classification

---

# 🧱 Phase 2 — Building Archetypes (Replace per-window logic)

### Goal

Move from “placing windows” → “assigning façade types”

### Prompt

> Based on filtered OSM building data, help me design a system that assigns each building (or face) a façade archetype (e.g. residential, office, industrial, blank, stylized).
>
> Requirements:
>
> * use OSM tags when available
> * fall back to heuristics when tags are missing
> * include randomness for variation (seeded)
> * avoid repetitive patterns across nearby buildings
>
> Provide:
>
> * a rule system
> * data structure for archetypes
> * example assignment logic

---

# 🎨 Phase 3 — Texture Atlas Design

### Goal

Introduce textures **without increasing draw calls**

### Prompt

> I want to replace vertex colors with a texture atlas while keeping a single merged mesh and material in Three.js.
>
> Help me design:
>
> * a façade texture atlas (what textures to include and how to organize them)
> * UV region layout strategy
> * how to map building archetypes to atlas regions
>
> Constraints:
>
> * must remain one material / one draw call
> * should support variation (not repetitive)
>
> Include diagrams or clear coordinate examples if possible.

---

# 🧩 Phase 4 — UV Generation for Extruded Geometry

### Goal

Make your merged mesh compatible with textures

### Prompt

> I generate extruded building meshes from OSM footprints.
>
> Help me implement UV mapping for:
>
> * vertical walls (tileable façades)
> * roofs (different mapping strategy)
>
> Requirements:
>
> * works on merged geometry
> * avoids stretching
> * supports tiling (repeat textures vertically by height)
>
> Provide:
>
> * formulas for UV calculation
> * pseudo-code or JavaScript examples
> * how to handle different building heights cleanly

---

# ⚡ Phase 5 — Shader Integration (Atlas + Variation)

### Goal

Make textures look less repetitive without more draw calls

### Prompt

> I am using a texture atlas in Three.js with a single material.
>
> Help me write a shader (or material setup) that:
>
> * selects atlas regions per face or vertex
> * supports UV offsets/scaling
> * uses vertex color (or attributes) for variation (tint, brightness, etc.)
>
> Include:
>
> * GLSL shader snippets or Three.js material setup
> * how to pass per-face/vertex data into the shader

>
> Constraints:
